LingoDict

Offline English–Chinese dictionary

An offline English–Chinese dictionary for Windows and macOS. Look-up, 81 vocabulary books, spaced repetition, pronunciation and even a grammar checker all run on your machine; only the writing-check model is downloaded once. No account, no usage tracking.

What it does

Look up words. Search by English headword or by Chinese meaning; hits are highlighted in the list and in the entry. 21,319 headwords with phonetics, drawn from 81 vocabulary books.

Read through a book. Browse any of the 81 books entry by entry. Each book keeps a bookmark of where you stopped, the way a paper dictionary would.

Learn. SM-2 spaced repetition. After you flip a card it asks whether you recalled it, and each answer button also tells you when the word will come back. Daily limits for new and review cards are adjustable.

Hear it. The speaker next to a headword reads it with the system voice, offline. Every symbol in a transcription is clickable: tap æ and it says cat. There is a full IPA chart and a listening drill built around the contrasts Chinese speakers really mix up: θ/s, v/w, ɪ/iː, n/ŋ, l/r.

Check your writing. Paste a paragraph and get suggestions one by one, each openable in the entry pane. A quantized GECToR model runs locally through ONNX Runtime; the model is installed once from inside the app.

Get around. Synonyms and word families are links. Double-click any word in an example sentence to look it up, or select a phrase and right-click.

The Windows installer puts the app in %LOCALAPPDATA%\LingoDict and needs no administrator rights. The macOS build is not signed or notarized: the first time, right-click the app and choose Open, or run:

xattr -dr com.apple.quarantine /Applications/LingoDict.app

The grammar model for writing checks (about 123 MiB) is not in the installers. The first time you open the writing page, choose Download model and the app fetches it from GitHub Releases, verifies it and resumes if interrupted; you can also import a local file. Older versions are on the Releases page.

Build from source

You need the .NET SDK 9.

1. Get the code and the vocabulary data

git clone https://github.com/txwmemoria/lingo-dict
cd lingo-dict
git clone --depth 1 https://github.com/kajweb/dict data/kajweb-dict

The vocabulary books belong to kajweb/dict and are not redistributed in this repository; the 81 archives (about 71 MiB) come with the clone. Don’t run its download.py.

2. Build the dictionary database

dotnet run --project src/LingoDict.Importer

Optionally add ECDICT first for word frequency and inflected forms (so cancelled finds cancel).

3. Run it

dotnet run --project src/LingoDict.App

Data and model

The code is one thing; what it reads is another. The vocabulary data stays with kajweb/dict. The grammar model is derived from gotutiyan/gector, whose training data is licensed for non-commercial use only, so the installers leave it out. It lives in model-v1 and the app downloads it when you need it.
