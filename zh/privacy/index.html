隐私说明

SDK Pods 是一家小型独立工作室。本页说明你使用本网站、网页小游戏、LingoDict 与 sw 命令行工具时，涉及哪些数据。最后更新：2026-11-23。

网站

本站是静态网站，没有账户，不需要注册，也没有联系表单。SDK Pods 没有在站内部署自有的访问统计，也不保存访客数据库。

广告（Google AdSense）

本站（sdkpod.com）展示由 Google AdSense 提供的广告。Google 及其合作伙伴可能使用 Cookie 或类似技术来展示和衡量广告，并可能根据你之前访问本站及其他网站的记录展示个性化广告。

  • 了解 Google 如何使用来自合作网站的数据，请参阅 policies.google.com/technologies/ads。
  • 如需关闭个性化广告，请访问 adssettings.google.com。
  • 在欧洲经济区和英国，广告加载前 Google 可能会显示同意提示。

网页小游戏

/games/ 中的小游戏只把分数、设置和成就保存在你浏览器的 localStorage 里，即保存在你自己的设备上。游戏数据不会发送给 SDK Pods。清除浏览器的网站数据即可删除这些内容。

游戏还会使用两项外部服务：

  • 天气使用免费的 Open-Meteo API，位置信息是粗略的。默认情况下，城市根据浏览器的时区选取。只有当你点击「使用我的位置」时，游戏才会请求你的定位，并且只发送保留两位小数的经纬度。
  • 音乐在你开启后，从 archive.org 流式播放。

上述服务与任何网络请求一样，会收到常规的连接信息，包括你的 IP 地址，并受其各自隐私政策约束。

偏好设置

你选择的浅色或深色主题，以及语言选择，都保存在浏览器的 localStorage 中，不会离开你的设备。

LingoDict 与 sw 命令行工具

桌面应用 LingoDict 与 sw 命令行工具不包含任何统计分析代码，也不会向我们回传使用情况。LingoDict 只有在你选择下载写作检查模型时才会联网，模型从 GitHub Releases 获取。查词、词书等其他功能都在你的电脑上运行。

托管与服务器日志

本站托管在 GitHub Pages 和 Cloudflare 上。在正常运行中，它们的服务器可能会记录 IP 地址和请求信息。这些日志受 GitHub 与 Cloudflare 各自的隐私政策约束。

政策变更

如果我们的做法有所变化，我们会更新本页，并修改页首的日期。
