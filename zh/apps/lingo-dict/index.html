LingoDict

离线英汉词典

Windows / macOS 上的英汉词典，从头到尾不联网。查词、81 本词书、间隔重复背单词、朗读，连语法检查都跑在本机。不联网、不注册、不上报。

能做什么

查词。英文词头或中文释义都能搜，列表和释义里都会高亮命中的部分。21,319 个词头带音标，取自 81 本词书。

逐本读。81 本词书可以一个词一个词地翻，每本书各记一个书签，记住你上次看到哪儿——纸质词典的习惯，去掉纸。

背单词。SM-2 间隔重复。翻面后先问一句「刚才想起来了吗」，四个按钮上行是你记得怎么样，下行是这个词下次什么时候再出现。每日新词和复习上限可调。

听发音。词头旁的喇叭用系统语音朗读，完全离线。音标里每个音都能点——点 æ 它念 cat。还有完整的音标表和听音辨词练习，练的全是中文母语者真会混的对立：θ/s、v/w、ɪ/iː、n/ŋ、l/r。

检查写作。贴一段英文，逐条给建议，每条都能在右侧打开词条核对。本地运行量化过的 GECToR 模型（ONNX Runtime），模型在应用里装一次即可。

到处跳。同近义词、同根词可点击直达。例句里双击单词就查，划选后右键查整段。

下载

系统文件
Windows 10/11（x64）LingoDict-0.5.1-win-x64-Setup.exe
macOS，Apple 芯片LingoDict-0.5.1-osx-arm64.dmg
macOS，Intel 芯片LingoDict-0.5.1-osx-x64.dmg

Windows 版装到 %LOCALAPPDATA%\LingoDict，不需要管理员权限。macOS 版没有签名和公证，第一次打开要右键 →「打开」，或者执行：

xattr -dr com.apple.quarantine /Applications/LingoDict.app

写作检查用的语法模型不在安装包里（它仅限非商业用途），第一次打开写作页时应用会提示安装。历史版本见 Releases 页面。

从源码构建

需要 .NET SDK 9。

1. 取代码和词书数据

git clone https://github.com/txwmemoria/lingo-dict
cd lingo-dict
git clone --depth 1 https://github.com/kajweb/dict data/kajweb-dict

词书数据属于 kajweb/dict，本仓库不再分发一次；81 个压缩包（约 71 MiB）克隆下来就有，不用跑它的 download.py。

2. 生成词典数据库

dotnet run --project src/LingoDict.Importer

可选：先加上 ECDICT 的词频和词形变化，输入 cancelled 也能落到 cancel。

3. 运行

dotnet run --project src/LingoDict.App

数据和模型

代码是一回事，它读的东西是另一回事。词书数据留在 kajweb/dict。语法模型衍生自 gotutiyan/gector，其训练数据仅限非商业用途，所以任何安装包都不打包它，而是在第一次打开写作页时由应用下载或从本地导入。
